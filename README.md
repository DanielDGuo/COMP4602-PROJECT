Run Parser.py to fetch data from PokéAPI and generate matchup files as output(requires 2GB of free storage, and may take half a day to compute output files). 

Run DifferenceCalc.py to output Cosmograph.app point and link datasets based on average edge weight and directed edges
Use MatchupFinder.py to search output files for specific matchups

NOTE:
Included are the matchup files and other outputs. Only run if needed.
PokéAPI key not required. Pokémon and Move data is requested when needed when running Parser.py.
